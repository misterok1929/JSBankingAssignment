# Banking App – JavaScript Assignment

A simple banking app built for my JavaScript Essentials course.
Users can check their balance, make deposits and withdrawals,
and view their transaction history.

## Live demo
https://misterok1929.github.io/JSBankingAssignment/

## Features
- View account balance
- Deposit and withdraw money
- Transaction history saved in the browser (localStorage)
- Input checks (e.g. can't withdraw more than the balance)

## How to run
- Open the live demo link above, or
- Clone the repo and open `index.html` in your browser:
  git clone https://github.com/misterok1929/JSBankingAssignment.git

## Built with
- HTML
- CSS
- JavaScript

## File structure
- `index.html` / `home.js` – main page
- `newentry.html` / `newentry.js` – add a transaction
- `vault.html` / `vault.js` – view saved records
- `storage.js` – saving and loading data

## What I learned
- Handling events and updating the page with JavaScript
- Storing data with localStorage
- Splitting code across several files
